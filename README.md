# Mi Primer Proyecto de Terraform

¡Bienvenido! Este repositorio lo uso para aprender y dar mis primeros pasos con **Terraform**.

## ¿De qué trata este proyecto?
Terraform es una herramienta que sirve para **crear y guardar la configuración de servidores y redes usando código** (esto se llama Infraestructura como Código o IaC). En lugar de hacer clics en páginas web para crear cosas, escribimos texto.

En este proyecto voy a aprender a:
* Conectar Terraform con la nube.
* Crear mis primeros recursos (como servidores virtuales).
* Entender cómo se automatizan los sistemas.
